# Enterprise Campus Network – Cisco Packet Tracer

A multi-site enterprise campus network implementation completed using Cisco Packet Tracer.

This project demonstrates the configuration, verification, security, redundancy, and troubleshooting of an enterprise network containing core, distribution, and access layers.

## Project Origin

This project is based on the CCNA Mega Lab created by Jeremy's IT Lab.

The original topology and requirements were provided as part of the lab. My work included configuring the network devices, implementing the required technologies, verifying network functionality, troubleshooting issues, and documenting the completed solution.

I do not claim ownership of the original lab topology or requirements.

## Technologies Implemented

- VLANs and trunking
- Layer 2 and Layer 3 EtherChannel
- VTP
- Rapid PVST+
- HSRPv2
- OSPF
- Static and floating default routes
- DHCP and DHCP relay
- DNS, NTP, SNMP, Syslog and FTP
- SSH remote access
- Static NAT and dynamic PAT
- Standard and extended ACLs
- Port security
- DHCP snooping
- Dynamic ARP Inspection
- IPv6 addressing and routing
- Wireless LAN Controller and lightweight access points
